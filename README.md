<h2> 🖋️ Project Description 🖋️ </h2>

> **Risoteria Formaggio di Minas** is a fictional web application developed to represent a specialized risotto restaurant.  
The main goal of this project is to create a digital menu that presents different varieties of risottos in an organized, attractive, and responsive way.

The application simulates a real restaurant menu, allowing users to explore different categories of risottos, including meat-based, chicken, seafood, and vegan options. The focus is on visual presentation, usability, and responsiveness across multiple screen sizes.

---

<h2> 🖌️ Project Styling 🖌️ </h2>

The project was designed with a clean, minimalistic and elegant visual identity, inspired by traditional Italian cuisine combined with a modern web interface.  
The layout was planned to resemble a digital restaurant menu, prioritizing readability, hierarchy of information, and visual appeal.

The interface was structured to adapt seamlessly to different devices, following responsive design principles:

- **Small screens (mobile):** 360px width  
- **Medium screens (tablet):** 768px width  
- **Large screens (desktop):** 1440px width  

---

<h3> 💭 Product Concept 💭 </h3>

The concept behind *Formaggio di Minas* is to combine the sophistication of Italian risotto cuisine with the warmth and authenticity associated with Minas Gerais gastronomy.  
The name itself reflects this fusion, reinforcing the idea of comfort food presented in a refined way.

The application aims to provide a pleasant browsing experience, similar to reading a well-designed physical menu in a high-quality restaurant.

---

<h4> 🤔 Logo 🤔 </h4>

The **Formaggio di Minas** logo was developed with the assistance of **Microsoft Copilot (AI)**.  
The objective was to create a visual identity that conveys elegance, simplicity, and a strong connection to gastronomy.

The logo was designed to be versatile, allowing its use across different sections of the application without compromising legibility or visual consistency.

<h2> 💨 How to Use the Application 💨 </h2>

Upon accessing the main page, the user is presented with the digital menu of **Risoteria Formaggio di Minas**.  
The menu sections are clearly divided by risotto categories, allowing easy navigation and exploration of the available options.

Users can scroll through the page to view each category and its respective dishes.  
The layout automatically adapts to different screen sizes, ensuring a consistent experience on mobile devices, tablets, and desktops.

<h2> 🧗‍♂️ Challenges Faced During Development 🧗‍♂️ </h2>

The main challenge of this project was the use of **Bootstrap**, a framework that I had never worked with before.  
Understanding Bootstrap’s grid system, predefined components, and utility classes required additional study and experimentation.

Throughout the development process, this challenge became an important learning opportunity, allowing me to expand my front-end skill set and improve my ability to adapt to new tools and frameworks commonly used in the industry.
